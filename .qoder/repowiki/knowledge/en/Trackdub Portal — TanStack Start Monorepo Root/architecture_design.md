The repository is a single-package TanStack Start project with two parallel build targets. The main SSR app is configured through `@lovable.dev/vite-tanstack-config` in `vite.config.ts`, which delegates plugin setup to Lovable and only overrides the Nitro server entry to point at `src/server.ts`. A second Vite config (`vite.sites.config.ts`) builds static client assets into `dist/client` using React + Tailwind with an `@` path alias. The `index.html` shell boots the client via `/src/sites.tsx`, while the server-side fetch handler and error middleware are handled by the app_entry child. Build orchestration runs `vite build` twice (default then sites config) followed by `scripts/prepare-sites-build.mjs` to merge outputs. Shared tooling (TypeScript strict mode, ESLint with React Hooks + Prettier, shadcn/ui aliases, Tailwind v4) is declared once at this level and consumed by all children.
